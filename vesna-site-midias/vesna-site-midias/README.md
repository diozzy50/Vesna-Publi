# Mídias do site Vesna Publi

Suba esta pasta mantendo a estrutura (assets/...). Os caminhos são os mesmos usados no index.html.

- assets/v: vídeos (hero e túnel)
- assets/img: fotos de seções (sobre, números, serviços, projetos, celular, janela)
- assets/sv: fotos dos cartões de serviços
- assets/cr: peças da seção Criativos
- assets/emb: embaixadores e logos parceiros
- assets/logos e assets/logos-sq: logos de clientes e afiliados
